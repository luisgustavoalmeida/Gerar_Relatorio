🚀 INÍCIO RÁPIDO (2 PASSOS):

1️⃣  VERIFICAR PYTHON:

    Abra CMD e execute:
    └─ python --version

    Se não aparecer versão:
    └─ Instale Python 3.12+ em: https://www.python.org/downloads/
    └─ IMPORTANTE: Marque "Add Python to PATH" na instalação!

2️⃣  COMPILAR O PROGRAMA:

    Duplo-clique em:
    └─ compilar.bat

3️⃣  RESULTADO:

    Executável gerado em:
    └─ dist\Gerar_Relatorio.exe

──────────────────────────────────────────────────────────────────

📁 ESTRUTURA APÓS A PRIMEIRA EXECUÇÃO DO .EXE:

(pasta do executável)
├── 🎯 Gerar_Relatorio.exe      ← EXECUTE ESTE ARQUIVO
├── 📂 template/                 ← Modelos Excel e configs
├── 📂 dados_rdo/                ← JSON por cliente
└── 📂 saida_relatorios/         ← Relatórios gerados

Na primeira execução, as pastas acima são criadas automaticamente
ao lado do .exe (copiadas do bundle interno).
